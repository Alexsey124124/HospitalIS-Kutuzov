# HospitalIS — информационная система «Больница»

Курсовой проект. ИС для учёта пациентов, врачей, приёмов, консультаций и диспансерного
наблюдения. ASP.NET Core MVC, слоистая архитектура, SQLite.

## Стек
- .NET 10, ASP.NET Core MVC (Razor Views)
- Entity Framework Core + SQLite (Code First, автосоздание БД и сидинг)
- Cookie-аутентификация, хэширование паролей PBKDF2 (без внешних пакетов)
- xUnit + Moq — модульные тесты бизнес-логики
- HTML/CSS/JS без внешних фреймворков

## Архитектура (слоистая)

    HospitalIS.Domain          сущности и enum'ы предметной области
    HospitalIS.Infrastructure  DbContext, репозитории (Repository<T>), сидеры
    HospitalIS.Application     DTO и сервисы — вся бизнес-логика и проверки
    HospitalIS.WebApi          MVC-контроллеры, Views, аутентификация, роли
    HospitalIS.Tests           модульные тесты сервисов

Правило зависимостей: Domain ← Infrastructure ← Application ← WebApi.
UI-слой заменяем (изначально был Web API, затем переведён на MVC) без правок бизнес-логики.

## Функциональные модули
1. **Справочники и учёт**: врачи, пациенты, специальности — полный CRUD.
2. **Записи на приём**: пациент записывается сам или через администратора; статусы из enum.
3. **Консультации**: врач проводит приём по записи, выставляет диагноз МКБ-10,
   вносит лечение (медицинская запись 1-к-1); одна запись — одна консультация.
4. **Диспансерный учёт**: постановка пациента на учёт по диагнозу, но только после
   проведённой консультации с ним; дата следующего визита, статусы наблюдения.
5. **Справочник диагнозов (МКБ-10)**: CRUD с контролем уникальности кода и защитой
   от удаления диагноза, используемого в консультациях/диспансере.
6. **Безопасность**: регистрация, вход, роли; все проверки прав и владельца — на сервере.

## Ролевая модель
| Действие | Пациент | Врач | Администратор |
|---|:--:|:--:|:--:|
| Справочники (врачи/спец./диагнозы) | просмотр | просмотр | CRUD |
| Пациенты: список / карточка | — / только своя | просмотр | CRUD |
| Записи: список | только свои | только свои | все |
| Записи: создать | себе | — | любому |
| Записи: смена статуса / удаление | — | свои | любые |
| Консультации и медзаписи | просмотр своих | ведёт свои | все |
| Диспансерный учёт | просмотр своего | ведёт свой | все |

## Запуск
1. Открыть `HospitalIS.sln` (Visual Studio 2022+, нагрузка .NET 10).
2. Нажать F5. База `hospital.db` создаётся и заполняется демо-данными автоматически.
3. Войти под одной из учётных записей.

### Демо-доступы
| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin123` |
| Врач | `ivanov` | `password123` |
| Пациент | `petrov` | `password123` |

Регистрация новых пользователей открыта (роли Patient/Doctor).
